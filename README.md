# Solo Radio

Ứng dụng nghe đài phát thanh trực tuyến gọn nhẹ, hỗ trợ phát trực tiếp các kênh radio Việt Nam và toàn cầu thông qua Radio Browser API.

## Tính năng
- Trình phát âm thanh trực tiếp (Live Audio Player).
- Danh sách gợi ý VOV1, VOV3, VOH và tìm kiếm toàn cầu.
- Quản lý kênh Yêu thích và Thêm đài tùy chỉnh.
- Hẹn giờ tắt (Sleep Timer) thông minh.
